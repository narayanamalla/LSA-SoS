# Low Speed Aerodynamics (LSA) Mentorship Program ✈️

Welcome to the 8-Week Low Speed Aerodynamics Mentorship repository! This project is designed to provide a structured, hands-on journey from the foundational equations of fluid motion to advanced computational aerodynamic methods.

## 📌 Program Overview
This repository contains weekly reading materials, project tasks, and code/simulation files for an 8-week deep dive into Low Speed Aerodynamics. The program bridges the gap between theoretical physics (Navier-Stokes, Potential Flow) and practical engineering applications (Airfoil Design, Lifting Line Theory, Panel Methods).

## 🛠️ Tools & Prerequisites
To get the most out of this mentorship, the following tools are recommended:
* **Simulation Software:** ANSYS Fluent (Highly recommended for hands-on CFD experience).
* **Documentation:** LaTeX (via Overleaf) or Google Docs for professional report formatting.
* **Math/Plotting:** Python (NumPy, Matplotlib) or MATLAB for plotting velocity profiles and solving panel method matrices.

## 📅 Course Structure
* **Week 1:** Governing Equations & Special Flow Conditions
* **Week 2:** Boundary Layer Dynamics & Separation
* **Week 3:** Inviscid Flows & Potential Flow Fundamentals
* **Week 4:** Vortex Dynamics & The Generation of Lift
* **Week 5:** Inviscid Airfoil Modeling (Thin Airfoil Theory)
* **Week 6:** Airfoil Geometry & Wing Parameters
* **Week 7:** 3D Aerodynamics & Lifting Line Theory
* **Week 8:** Computational Approaches (Panel Methods & VLM)

## 🎯 Key Deliverables
Mentees are expected to complete the following milestones throughout the program:
1. **Weekly Activities:** Practical derivations, code snippets, or sketches.
2. **Mid-Term Report:** Documenting findings and theory from Weeks 1-4.
3. **End-Term Report:** A comprehensive project document covering the entire 8 weeks.
4. **Video Presentation:** A final video explaining the project document and key takeaways.

*Stay consistent, do not leave activities to the last minute, and enjoy the learning process!*
